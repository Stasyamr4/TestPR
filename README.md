## Ход выполнения

### 1. Рефакторинг кода и добавление XML-комментариев

В проекте WPF-приложения из практической работы №4 были выделены три математические функции в отдельные статические методы соответствующих страниц (`Page1`, `Page2`, `Page3`). Для каждого метода добавлены XML-комментарии с описанием параметров, возвращаемого значения и выбрасываемых исключений.

- **`Page1.Calculate(double x, double y, double z)`** – вычисляет  
  `a = 2^(-x) * sqrt(x + |y|^(1/4) * sqrt(e^(x-1)/sin(z)))`.  
  Проверяет, что `sin(z) != 0` и подкоренное выражение неотрицательно.
- **`Page2.Calculate(double x, double m, Func<double,double> func)`** – вычисляет `k` в зависимости от `|x*m|`:  
  - если `|x*m| > 10`: `k = ln(|f(x)| + |m|)`
  - если `|x*m| < 10`: `k = e^(f(x) + m)`
  - если `|x*m| == 10`: `k = f(x) + m`  
  Требует, чтобы переданная функция `func` не была `null`.
- **`Page3.ComputeY(double x, double b)`** – вычисляет  
  `y = x·sin(√x + b – 0.0084)`.  
  Проверяет, что `x ≥ 0`, иначе выбрасывает исключение.

### 2. Создание проекта модульных тестов

В решение был добавлен новый проект **UnitTestProject** с использованием шаблона «Проект модульного теста» (MSTest). В проект добавлена ссылка на основной проект WPF-приложения. Для корректной работы тестов в файл проекта `.csproj` была добавлена настройка `<UseWPF>true</UseWPF>`, а также установлены необходимые сборки (`WindowsBase`, `PresentationCore`, `PresentationFramework`).

### 3. Написание тестов для первой функции (`Page1.Calculate`)

Были разработаны три теста:

- **Позитивный тест** `Calculate_ValidInputs_ReturnsCorrectResult` – проверяет корректность вычисления для допустимых значений `x=1.0`, `y=16.0`, `z=π/2`. Ожидаемое значение `0.5 * sqrt(3)` совпадает с результатом с точностью до `1e-6`.
- **Негативный тест 1** `Calculate_SinZEqualsZero_ThrowsArgumentException` – проверяет, что при `sin(z)=0` (например, `z=0`) выбрасывается исключение `ArgumentException`.
- **Негативный тест 2** `Calculate_NegativeUnderRoot_ThrowsArgumentException` – проверяет, что при отрицательном подкоренном выражении (например, `x=-100`, `y=1`, `z=π/2`) выбрасывается `ArgumentException`.

### 4. Написание тестов для второй функции (`Page2.Calculate`)

Были разработаны три теста:

- **Позитивный тест** `Calculate_AbsXqGreaterThan10_ReturnsCorrectLog` – проверяет ветку `|x*m| > 10` с функцией `f(x)=x^2`. При `x=10`, `m=10` ожидается `ln(110)`.
- **Негативный тест 1** `Calculate_NullFunc_ThrowsArgumentNullException` – проверяет, что при передаче `null` в качестве функции выбрасывается `ArgumentNullException`.
- **Негативный тест 2** `Calculate_FuncReturnsNaN_ReturnsNaN` – проверяет, что если функция возвращает `NaN`, результат также будет `NaN` (исключение не выбрасывается).

### 5. Написание тестов для третьей функции (`Page3.ComputeY`)

Были разработаны три теста:

- **Позитивный тест** `ComputeY_ValidInput_ReturnsCorrectValue` – проверяет вычисление для `x=4`, `b=0`. Ожидаемое значение `4 * sin(2 - 0.0084)`.
- **Негативный тест 1** `ComputeY_NegativeX_ThrowsArgumentException` – проверяет, что при `x < 0` выбрасывается `ArgumentException`.
- **Негативный тест 2** `ComputeY_NaNInput_ReturnsNaN` – проверяет, что при передаче `x = double.NaN` результат также `NaN`.

## Вывод

В ходе выполнения практической работы:

- Выполнен рефакторинг кода: логика вычислений трёх математических функций вынесена в отдельные статические методы, добавлены XML-комментарии.
- Создан проект модульных тестов на базе MSTest, настроены ссылки на необходимые сборки WPF.
- Для каждой функции разработаны три теста: один позитивный (проверка корректного сценария) и два негативных (проверка обработки ошибочных ситуаций).
- Все тесты успешно выполняются, что подтверждает корректность реализованных методов и их устойчивость к некорректным входным данным.
- Автоматизированное тестирование позволило убедиться в правильности работы математических функций и обеспечить защиту от регрессий при дальнейших изменениях кода.

Таким образом, цель работы достигнута: освоены приёмы создания модульных тестов методом «белого ящика» и проведено тестирование трёх функций из практической работы №4.
