## Описание предметной области — Шифр Виженера

**Шифр Виженера** — полиалфавитный шифр, использующий ключевое слово для циклического сдвига символов. В отличие от шифра Цезаря (фиксированный сдвиг), здесь сдвиг каждой буквы зависит от соответствующей буквы ключа.

---

### Требования к реализации

- Поддержка двух алфавитов (русский / английский) с сохранением регистра.
- Автоповтор ключа до длины текста.
- Сохранение неалфавитных символов на своих местах.
- Обработка исключительных ситуаций:  
  `null`, пустая строка, пустой ключ, недопустимые символы в ключе.

## Диаграмма вариантов использования

Диаграмма хранится в файле  
`diagram.png` (в корне репозитория).

**Актёр:** Пользователь  

**Варианты использования:**

| Use Case | Описание |
|----------|----------|
| Задать открытый текст | Ввод текста для шифрования / дешифрования |
| Задать ключевое слово | Ввод ключа (буквы, регистр не важен) |
| Зашифровать текст | Выполнить шифрование текста шифром Виженера |
| Расшифровать текст | Выполнить дешифрование с тем же ключом |
| Посмотреть результат | Отобразить результат операции |
| Обработать ошибки | Валидация полей ввода (пустые строки, null, неверные символы) |
| Сбросить поля | Очистить все поля ввода и вывода |

**Связи:**
- «include» – шифрование и дешифрование **включают** отображение результата.
- «extend» – шифрование / дешифрование могут **расширяться** обработкой ошибок.
