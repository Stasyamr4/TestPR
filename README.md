## Постановка задачи
Разработать приложение для табуляции функции:

**y = x·sin(√x + b - 0.0084)**

где:

* x — аргумент функции (вводится пользователем для одиночного вычисления)

* b — параметр функции

* X0 — начальное значение интервала табуляции

* Xk = X0 + 1 — конечное значение интервала (вычисляется автоматически)

* dx — шаг табуляции

Результаты должны выводиться в виде диаграммы.

## Функциональные возможности
### Ввод данных

* Поле для ввода значения x (одиночное вычисление)

* Поле для ввода параметра b
 
* Поле для ввода начального значения X0

* Поле для ввода шага табуляции dx

* Автоматическое вычисление и отображение Xk = X0 + 1

### Вычисления
* Проверка корректности вводимых данных

* Проверка области определения функции (x ≥ 0 из-за квадратного корня)

* Табуляция функции на интервале [X0, Xk] с шагом dx

* Вывод таблицы значений (все пары x и y)

### Визуализация
* Построение графика функции на заданном интервале

* Отображение точек на графике

* Подписи начальной и конечной точек

* Автоматическое масштабирование осей

### Управление
* Кнопка «Вычислить» — запуск расчётов и построение графика

* Кнопка «Очистить» — сброс всех полей и очистка результатов

## Реализация
Вычисление функции
```csharp
// Вычисление значения функции
double sqrtX = Math.Sqrt(currentX);
double argument = sqrtX + b - 0.0084;
double y = currentX * Math.Sin(argument);
```
Табуляция функции
```csharp
for (double currentX = x0; currentX <= xk + 1e-10; currentX += dx)
{
    if (currentX < 0) continue; // Проверка области определения
    
    double y = currentX * Math.Sin(Math.Sqrt(currentX) + b - 0.0084);
    results.AppendLine($"x = {currentX:F4} \t y = {y:F6}");
}
```
Построение графика
```csharp
// Инициализация диаграммы
ChartPayments.ChartAreas.Add(new ChartArea("MainArea"));

// Создание серии данных
var series = new Series("Функция y = x·sin(√x + b - 0.0084)")
{
    ChartType = SeriesChartType.Line,
    BorderWidth = 3,
    Color = System.Drawing.Color.Blue,
    MarkerStyle = MarkerStyle.Circle,
    MarkerSize = 8
};

// Добавление точек
for (double x = x0; x <= xk + 1e-10; x += dx)
{
    if (x >= 0)
    {
        double y = x * Math.Sin(Math.Sqrt(x) + b - 0.0084);
        series.Points.AddXY(x, y);
    }
}
```
Автоматическое обновление Xk
```csharp
private void UpdateXkValue()
{
    if (double.TryParse(txtX0.Text, out double x0))
    {
        txtXk.Text = (x0 + 1).ToString("F2");
    }
}
```
